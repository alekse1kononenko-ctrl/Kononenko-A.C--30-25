# Практическая работа № 3, вариант 13

Переводчик учебного конфигурационного языка в TOML.
Основание: рабочая тетрадь «ИКБО-30-25-3», общие требования на
страницах 4-7, вариант 13 на страницах 30-31.

## Этап 1. Грамматика

Реализован полный синтаксический разбор с Lark LALR(1).
Грамматика находится в `src/grammar.lark`, обработка ошибок в
`src/errors.py`, загрузка анализатора в `src/parser.py`.

Python 3.11 или новее, зависимости и проверка:

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

Синтаксис взят только из варианта 13. Целые числа разрешены только
внутри выражений, поскольку в примере тетради приведено `$+ имя 1$`.
Имена регистрозависимы; `pow()` записывается в префиксной форме
`$pow основание показатель$`. Массивы могут быть пустыми и вложенными.

Официальная документация Lark:
https://lark-parser.readthedocs.io/en/stable/grammar.html

## Этап 2. Вычисления и TOML

`src/evaluator.py` последовательно вычисляет объявления и хранит константы.
`src/arithmetic.py` реализует `+`, `-`, `*`, `/`, `pow`.
`src/translator.py:translate(source)` возвращает готовый текст TOML.
Для сериализации применяется Tomli-W; тесты читают результат через tomllib.
Строки сохраняются буквально, массивы могут содержать разные типы.
Числа вычисляются как Python float; переполнение, деление на ноль,
неизвестные имена, повторные объявления и неверные типы дают ошибки.
Максимальная суммарная вложенность массивов и выражений: 64.

Официальные источники:
https://github.com/hukkin/tomli-w
https://docs.python.org/3.12/library/tomllib.html
