# Встраиваемая игровая платёжная система

Библиотека C++ для операций с виртуальными монетами и демонстрационный магазин для macOS. На первом этапе реализован кошелёк с начислением целых монет и проверкой суммы. Покупки, сохранение и графический интерфейс описаны в [проекте системы](docs/design.md).

## Сборка и тесты кошелька

Откройте каталог `coursework-game-payments` в терминале. Для сборки нужны CMake 3.20 или новее и компилятор C++17. На macOS компилятор входит в Command Line Tools. Из Qt Creator можно открыть этот `CMakeLists.txt` как проект.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Цель `game_payments` собирается как статическая библиотека. Другой CMake-проект может добавить этот каталог через `add_subdirectory` и указать `target_link_libraries(имя_игры PRIVATE game_payments)`. Публичный заголовок первого этапа — `game_payments/wallet.hpp`.

Исходный код проекта распространяется по лицензии [MIT](LICENSE).
