# Эмулятор оболочки ОС Вариант 13

Практическая работа по дисциплине «Конфигурационное управление».
Этап 1: CLI, приглашение с именем VFS, раскрытие переменных реальной
ОС, заглушки ls и cd, exit, обработка ошибок.

Python 3.10 или новее. Используется только стандартная библиотека.
Сборка и установка пакетов не требуются.

Запуск: `python -m src.main` или `run.bat`.
Тесты: `python -m unittest discover -s tests -v`.

Примеры: `ls "$HOME"`, `cd /home`, `exit`.
`src/parser.py` разбирает слова, кавычки, экранирование и переменные.
`src/shell.py` хранит состояние и выполняет команды.
`src/main.py` запускает REPL. Настроек первого этапа нет.
